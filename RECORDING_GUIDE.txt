--------------------------------------------------------------
STEP 1: START WEBSITE
--------------------------------------------------------------
1. Open Command Prompt
2. Type: cd "E:\Advance Database\student_exchange_system"
3. Type: python app.py
4. Wait for "Running on http://127.0.0.1:5000"
5. Keep this window OPEN

--------------------------------------------------------------
STEP 2: START RECORDING
--------------------------------------------------------------
Method A - Xbox Game Bar (Built-in):
1. Press Win + G
2. Click "Start Recording" (or Win + Alt + R)
3. You will see a timer at top-right

Method B - OBS Studio (Free download):
1. Download from obsproject.com
2. Open OBS
3. Click "Start Recording"

--------------------------------------------------------------
STEP 3: RECORD VIDEO (Follow the script)
--------------------------------------------------------------
Open Chrome browser and follow VIDEO_SCRIPT.txt:

Second 0:00-1:00 - Show homepage, introduce yourself
Second 1:00-2:00 - Click "Database", show tables

Second 8:30-9:30 - Open app.py in Notepad, show code
