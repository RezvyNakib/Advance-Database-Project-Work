15.3 Database Connection Process

Step-by-step description of how the website connects to the database:

Step 1: Installed Python Flask framework using pip command:
        python -m pip install flask

Step 2: Created db_config.py file with get_connection() function:
        import sqlite3
        def get_connection():
            conn = sqlite3.connect('student_exchange.db')
            conn.row_factory = sqlite3.Row
            return conn

Step 3: In app.py, imported the connection function:
        from db_config import get_connection

Step 4: Each route function calls get_connection() to connect:
        @app.route('/student')
        def student_dashboard():
            conn = get_connection()
            c = conn.cursor()
            c.execute("SELECT * FROM Student")
            students = c.fetchall()
            conn.close()
            return render_template('student_dashboard.html', students=students)

Step 5: SQL queries execute through cursor object to read/write data

Step 6: Data displays on the web interface using HTML templates

Step 7: Connection closes automatically when request completes

15.4 Database Tables

The following 6 tables were created matching the Oracle schema:

1. University (Uni_Id, Uni_Name, Country, Address)
2. Coordinator (Coordinator_Id, Coordinator_Name, Email, Phone, Uni_Id)
3. Exchange_Program (Program_Id, Semester, Duration, Field_Of_Study, Max_Students, Uni_Id, Coordinator_Id)
4. Student (Student_Id, Student_Name, Department, CGPA, Email)
5. Student_Phone (Student_Id, Phone)
6. Application (Application_Id, Application_Date, Status, Student_Id, Program_Id)
